## Decisions and trade-offs
- One predefined demo student replaces account creation and authentication for the MVP.
- PostgreSQL stores registrations and hour logs.
- Seeded opportunities replace an admin content-management interface.
- CI uses Jest/Supertest mocked database tests; live database integration must be checked manually.
