# VolunteerConnect

## Project Description
VolunteerConnect is a web application designed to help college students discover volunteer opportunities that align with their schedules, interests, and personal goals.

The application aims to simplify the process of finding volunteer opportunities while encouraging community involvement, networking, and personal development.

## Target Users
College students seeking volunteer experience, community engagement, networking opportunities, or service hours.

## Planned Core Features
- Volunteer opportunity listings and search filters
- Volunteer event registration
- Community service hour tracking
- Personal dashboard for upcoming events and completed hours
- AI-powered volunteer recommendations (final release)

## Planned Technology Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL
- **Containerization:** Docker
- **Version Control:** Git and GitHub
- **CI/CD:** GitHub Actions
- **Deployment:** Google Cloud Run
- **AI Development Tool:** GitHub Copilot

## Development Plan

### Sprint 1 — MVP (Unit 12)
Develop opportunity listings, search, registration, service-hour tracking, student dashboard, and initial cloud deployment.

### Sprint 2 — Final Application (Unit 14)
Implement opportunity details, registration cancellation, AI-powered recommendations, and final improvements.

## Project Status
Currently in the planning and development setup phase.
